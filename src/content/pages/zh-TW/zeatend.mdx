highlights:
  titleDim: 裝好之後，
  title: 也交給 Zeatend 維護
  items:
    - tag: doctor
      title: 檢查主機和叢集
      body: zeatend doctor 檢查叢集服務、API 伺服器和節點是否就緒，也檢查 Secret 有沒有加密儲存。沒通過的項目會寫出該執行的指令。
    - tag: node add
      title: 加入新的節點
      body: 在 server 上執行 zeatend node add，畫面會印出新 VM 要用的設定、指令和 join token，K3s 和 RKE2 叢集都能用。
    - tag: upgrade
      title: 一次升一個小版本
      body: 用新版的 Zeatend 執行 apply，就會升級這台主機。先一台一台升級 server，再升級 worker。版本差距超出 Kubernetes 的版本偏差政策時，apply 不做任何變更，並告訴你要先套用哪個版本。
how:
  titleDim: 在終端機裡，
  title: 看過計畫才安裝
  steps:
    - title: 選擇發行版
      body: 畫面顯示主機資訊和檢查結果，讓你選擇 K3s、RKE2 或 KubeSolo，三種都依 CIS 基準強化。
    - title: 確認安裝計畫
      body: 填好 API 伺服器的位址、DNS 名稱和節點名稱後，畫面列出要安裝的版本和設定，你確認後才開始安裝。
    - title: 開始安裝
      body: 主機有 systemd 時，安裝在 systemd 單元裡執行，SSH 斷線也不會中斷。再執行一次 sudo zeatend apply，就能接著看進度。
details:
  title: 常用的指令
  cols:
    - 指令
    - 用途
  rows:
    - - sudo zeatend
      - 開啟安裝畫面，可以選擇英文、繁體中文或簡體中文
    - - zeatend plan
      - 顯示 apply 會安裝哪些東西，並執行主機檢查；加上 --json 以 JSON 輸出計畫
    - - zeatend apply
      - 安裝，或讓現有的安裝符合設定檔，重複執行也沒有問題；--plan 套用先前輸出的計畫
    - - zeatend doctor
      - 檢查主機和叢集，以結束碼回報結果，可以接上監控
    - - zeatend node add
      - 印出新節點加入 K3s 或 RKE2 叢集要用的設定和指令
    - - zeatend uninstall
      - 移除叢集和 Zeatend 寫入的檔案；加上 --delete-volumes 才會刪除磁碟區

  title: 在伺服器上下載並安裝
  sub: 在要安裝叢集的 Linux 伺服器上執行下面的指令。主機要以 systemd 啟動，處理器是 amd64 或 arm64；K3s 至少要 2 GiB 記憶體，資料所在的磁碟至少要有 10 GiB 可用空間。
  cta: 閱讀完整的安裝說明
  anchor: 安裝
  hero: 在 Linux 伺服器上執行這幾行，就會開啟安裝畫面：
  steps:
    - title: 下載並核對 zeatend
      body: 下載 zeatend，再用 SHA256SUMS 核對檔案。sha256sum 印出 OK，代表下載的檔案和 GitHub release 上的檔案一致。
      code: download
    - title: 安裝叢集
      body: 在畫面上選擇 K3s、RKE2 或 KubeSolo，填好你的電腦連到 API 伺服器的位址，確認安裝計畫後開始安裝。不想開畫面時，先執行 sudo zeatend plan 檢視，再執行 sudo zeatend apply，會用預設值安裝 K3s；要裝 RKE2 或 KubeSolo，先把設定寫進 /etc/zeatend/config.yaml。
      code: install
    - title: 確認叢集可以使用
      body: 安裝完成時，畫面會顯示「叢集已經可以使用」，並列出查看節點和把 kubeconfig 複製到你電腦上的指令。之後隨時可以用 sudo zeatend doctor 檢查主機和叢集。
      code: check
