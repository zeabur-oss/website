details:
  title: 能做什麼，需要準備什麼
  cols:
    - 功能
    - 範圍
    - 叢集裡需要
  rows:
    - - 從 Git 部署
      - 推送後自動建置並部署
      - Zeabur Builder
    - - 映像檔與 Compose
      - 部署容器映像檔，匯入 Docker Compose 服務
      - 不用另外安裝
    - - 資料庫
      - 建立、備份與還原
      - 對應的資料庫 operator，例如 CloudNativePG
    - - 物件儲存
      - 建立 S3 物件儲存與儲存貯體
      - SeaweedFS operator
    - - 公開網域
      - 加上網域與 HTTPS，顯示維護與錯誤頁面
      - ingress controller 或 Gateway，以及 cert-manager
    - - 管理叢集
      - 成員權限、節點、警示通知、叢集備份、元件
      - 管理員權限
