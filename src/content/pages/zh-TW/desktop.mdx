highlights:
  titleDim: 叢集原本的樣子，
  title: 都會保留
  items:
    - tag: zeabur-local
      title: 叢集裡不用安裝 Zeabur
      body: Zeabur 在你的電腦上執行，和 zeaburctl ui 用的是同一個本機服務。它不會在叢集安裝元件，也不用準備網域和登入服務。
    - tag: Namespace
      title: 現有的應用程式照常運作
      body: 把既有的 Namespace 加成專案時，Zeabur 只加上專案標籤，裡面的服務、資料和安全性設定都保持原樣。不想用了，拿掉標籤就好。
    - tag: RBAC
      title: 用你自己的權限
      body: 讀取、檢查變更和套用，都用那個 context 的權限，叢集的 RBAC 照常生效。團隊只開了部分權限，Zeabur Desktop 就只做得到那些。

    - title: 就是你熟悉的 Zeabur
      body: 新視窗打開的是同一套 Zeabur 介面。有管理權限的話，叢集裡已經在跑的應用程式可以直接加成專案，不用重新部署。
    - title: 哪裡要處理，一眼就看到
      body: 首頁列出整個叢集裡需要處理的服務，用白話說明原因和接下來能做什麼，例如記憶體不夠時直接調整。
