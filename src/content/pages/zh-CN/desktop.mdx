titleDim: kubeconfig 里的集群，
title: 选一个就能打开
sub: Zeabur Desktop 列出你电脑上 kubeconfig 文件里的 context。选一个，它就在新窗口里为那个集群打开 Zeabur。做的事和 zeaburctl ui 一样，只是不用打开终端。

highlights:
  titleDim: 集群里不用安装，
  title: 用你自己的权限操作
  items:
    - tag: kubeconfig
      title: 直接用现有的 kubeconfig
      body: kubeconfig 文件里的每个 context，Zeabur Desktop 都会列出来。读取集群、检查变更和应用变更，都使用那个 context 的权限。
    - tag: zeabur-local
      title: 在你的电脑上运行 Zeabur
      body: 每个集群窗口都会启动自己的本地服务，和 zeaburctl ui 用的是同一个，所以集群里不用先安装 Zeabur 服务器。
    - tag: update
      title: 启动时检查更新
      body: 有新版本时，侧边栏会显示版本号。先看过更新内容，点击“更新并重启”才会安装。预发布版本不会出现在更新里。
how:
  titleDim: 从下载到打开，
  title: 只要三步
  steps:
    - title: 下载并安装
      body: 到发布页面下载适合你电脑的文件。Apple 芯片的 Mac 用 .dmg，Windows 用 -setup.exe，Linux 有 .deb、.rpm 和 AppImage。
    - title: 选一个集群
      body: Zeabur Desktop 列出 kubeconfig 文件里的 context，从中选出要打开的集群。
    - title: 在新窗口里使用 Zeabur
      body: 窗口里就是你熟悉的 Zeabur，项目、服务、域名和日志都在。每个打开的 context 都有自己的窗口。
details:
  title: 下载哪个文件
  cols:
    - 电脑
    - 文件
    - 新版本
  rows:
    - - Apple 芯片的 Mac
      - .dmg，打开后把 Zeabur 拖进“应用程序”
      - 自动更新
    - - x64 的 Windows
      - -setup.exe，只为你的账号安装，不需要管理员权限
      - 自动更新
    - - x64 的 Windows，免安装
      - -portable.exe
      - 提示新版本，到发布页面下载
    - - Debian 或 Ubuntu
      - .deb，amd64 或 arm64
      - 提示新版本，到发布页面下载
    - - Fedora、RHEL 或 openSUSE
      - .rpm，amd64 或 arm64
      - 提示新版本，到发布页面下载
    - - 其他 Linux
      - .AppImage，amd64 或 arm64
      - 自动更新
